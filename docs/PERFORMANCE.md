# 查询基准

运行:`npm run benchmark`(完整三档矩阵)或 `npm run benchmark -- 1000000`(单档)。仅使用脚本新建的临时 SQLite 数据库,完成后删除;不会访问或修改 ZCode 的真实数据库。`ZCODE_TPS_BENCH_SCRIPT=<token-rate.mjs 路径>` 可对任意版本脚本跑同一矩阵(优化前后对比)。

## 2026-09-15 矩阵(v0.5.3,优化前后对比)

- 环境:Windows、Node 24.14.0。合成库含真实分布(缓存命中 85% 行在 90-99%、输入/输出对数均匀、TTFT 2-14s、main_turn/subagent/辅助 ≈ 90/7.5/2.5%、少量 error/零输出/NULL 行),生成器与种子见 `test/fixture.mjs`。
- 索引场景:`no_indexes`(无索引)/ `legacy`(旧实验索引 `(session_id,status,query_source,completed_at)` 等)/ `real`(镜像生产库 3.11.2+ 的 4 个索引,含 `(session_id,turn_id)`、`(query_source)`、`(trace_id)`、`(started_at,provider_id,model_id)`)。
- 查询模式:典型会话(行数中位)/ 最大会话(2% 行)/ auto(自动识别,无显式会话)。hot=进程内 7 次中位(预热 1 次不含);cold=全新子进程首次查询(含模块加载),3 次中位。

### 100 万行(热查询中位,ms)

| 场景 | 模式 | 0.5.2(before) | 0.5.3(after) | 提升 |
|---|---|---:|---:|---:|
| real(生产索引) | 典型会话 | 3567.8 | 168.0 | ~21× |
| real(生产索引) | 最大会话 | 3064.3 | 481.6 | ~6.4× |
| real(生产索引) | auto | 5535.4 | 1105.9 | ~5.0× |
| 无索引 | 典型会话 | 3362.0 | 1082.8 | ~3.1× |
| 无索引 | 最大会话 | 6585.6 | 766.2 | ~8.6× |
| legacy 实验索引 | 典型会话 | 11.1 | 10.6 | 持平 |
| 持续独占锁(DELETE 日志) | — | 6551.0 | 6274.7 | 持平(<8s) |

冷启动(子进程首查,1M real):before 3476-3677ms → after 288-588ms。

### 优化内容与机理

1. **语句合并**:0.5.2 单次统计最多 13 条 SELECT 各自重复扫描(会话累计/有效样本/Decode/分布/轮次/子代理×3 各一条);0.5.3 合并为 ≤4 条(单遍条件聚合、材化 CTE、优先级排序会话识别、latest 优先从 history 派生),并有"SELECT 语句数 ≤ 8"回归门禁。
2. **索引路径固定**:生产索引 `(session_id,turn_id)` 不含 status/query_source,SQLite 缺少 ANALYZE 统计时规划器倾向弃用之而全表扫描(实测 1M 行 real 场景与无索引同速)。0.5.3 只读探测 session_id 首列索引并对会话等值语句 `INDEXED BY` 固定路径,这是 real 场景 21× 提升的主因。
3. **连接级 mmap(256MB)+ 页缓存(64MB)**:降低无索引大库全表扫描的每页系统调用成本。
4. **锁路径安全**:上述 pragma 若在连接打开时执行,遇独占锁会各自付出完整 busy 等待周期(实测锁场景 6.5s→12.8s,突破 hook 8s 预算);现移至 schema 首次成功读取之后,持锁时提前抛错,锁路径恢复 ~6.3s。

### 测量边界

- 包含每次 query 的只读连接、schema 检查、统计和关闭连接;不包含 Node 进程启动(hot)、hook 状态文件 IO、模型调用和 ZCode 界面开销。
- before 数据在后台运行期间有轻量并发测试,数字取偏保守上界;差距量级(5-21×)远超噪声。auto 场景运行间波动可达 ±40%(排序主导)。
- 持续独占锁场景在 DELETE 回滚日志模式下测量(与 0.4.2 基线可比);生产 WAL 模式下读走快照,几乎不被写者阻塞,该值代表最坏路径。接近 8 秒 hook 超时,仍需在真实客户端观察。

## 历史:2026-09-07 单场景测量(0.4.2)

10 万条均匀分布请求、20 会话、预热后 7 次采样:无索引中位 134.7ms(P95 145.6),实验索引 38.8ms(P95 45.1);持续独占锁 6,556.5ms 报 `database is locked`。该"实验索引"比生产索引覆盖面强,故 0.5.2 的索引收益被系统性高估——这是 2026-09-15 审计(P1-2)发现并由矩阵修正的问题。v0.5.3 同库同矩阵下 legacy 场景典型会话 13-19ms。
